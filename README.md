# MobInfoLoot (WoW 3.3.5a)

Легковесный аддон для World of Warcraft: Wrath of the Lich King (клиент 3.3.5a), который отображает подробную таблицу добычи (лута) для выбранного NPC через удобный интерактивный интерфейс.

## Особенности
* **Компактная база данных:** В памяти хранятся только ID мобов, ID предметов и вероятности дропа. Это уменьшает вес базы до ~3-5 МБ и обеспечивает мгновенную загрузку аддона.
* **Встроенное кэширование:** Названия предметов, цвета их качества (зеленый, синий, эпик) и иконки запрашиваются у клиента игры через `GetItemInfo`. Аддон автоматически работает на любом языке клиента (ruRU, enUS и т.д.).
* **Интерактивный UI:** Окно поддерживает прокрутку (ScrollFrame) для боссов с большим количеством лута. 
* **Поддержка ссылок:** При наведении на предмет отображается стандартная всплывающая подсказка (Tooltip). Поддерживается отправка предмета в чат (`Shift + ЛКМ`) и примерка (`Ctrl + ЛКМ`).

## Установка
1. Скачайте архив с аддоном.
2. Распакуйте папку `MobInfoLoot` в директорию игры: `World of Warcraft\Interface\AddOns\`.
3. Зайдите в игру и убедитесь, что аддон включен в меню модификаций на экране выбора персонажа.

## Использование
1. Возьмите в цель (таргет) любого враждебного или нейтрального NPC.
2. Зажмите клавишу **Shift** и кликните **Левой кнопкой мыши** по портрету вашей цели.
3. Откроется окно со списком всех предметов, которые могут выпасть с данного моба.

*Примечание: Если вы видите надпись «Неизвестно (Нажми для загрузки)», значит этого предмета еще нет в локальном кэше вашего клиента (папка WDB). Просто наведите курсор на предмет или кликните по нему, чтобы сервер прислал данные.*
